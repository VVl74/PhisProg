# Прогнозирование уровня аэродинамического шума

Итоговый проект по физике · Владислав Вейгандт

Нейросеть PyTorch прогнозирует масштабированный уровень звукового давления профиля NACA 0012 на заданной частоте. Пять входных параметров передаются в порядке **частота (Гц), угол атаки (°), хорда (м), скорость потока (м/с), толщина вытеснения пограничного слоя на стороне разрежения (м)**.

## Интерфейс в PyCharm

Выберите конфигурацию **Noise Interface** и нажмите ▶. Окно откроется с готовым примером.
Введите свои значения и нажмите **Рассчитать** или Enter. Справа отобразится уровень
на заданной частоте и весь прогнозируемый спектр от 200 до 20 000 Гц.
В полях поддерживаются точка и запятая. Для окна нужен Python с Tkinter.

Из терминала окно можно открыть командой `python noise_gui.py`.

## Запуск из терминала

Откройте папку проекта и выберите интерпретатор Python 3.10 или новее с установленным PyTorch.

```bash
python -m pip install -r requirements.txt
python airfoil_noise.py predict 800 1.5 0.3048 71.3 0.00336729
```

Готовая модель выдаст **128,34 дБ**. Измеренное значение для этой тестовой точки — **127,12 дБ**. При использовании Python из Anaconda на этом Mac команды можно запускать через `/opt/anaconda3/bin/python`.

Для повторного обучения и построения графиков выполните:

```bash
python airfoil_noise.py train
```

Результаты записываются в `results/`. В этой папке лежат веса модели, метрики, графики и CSV с прогнозами и измерениями на тесте. Ноутбук `physics_project.ipynb` содержит физическую постановку, разбор эксперимента и демонстрацию прогноза. Он открывается в Jupyter с уже сохранёнными результатами.

## Данные

В архив входит файл из 1503 строк с шестью числовыми столбцами. Их порядок соответствует порядку пяти входов, затем идёт целевой уровень в дБ. Числовые значения сохранены из исходного файла.

Brooks, T., Pope, D., & Marcolini, M. (1989). *Airfoil Self-Noise* [Dataset]. UCI Machine Learning Repository. [DOI 10.24432/C5VW2C](https://doi.org/10.24432/C5VW2C). Лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Физика источников шума и описание эксперимента приведены в [NASA Reference Publication 1218](https://ntrs.nasa.gov/citations/19890016302).
